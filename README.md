# 🚀 Discord Cleaner

**Discord Cleaner** — простое и удобное локальное веб-приложение для выборочной очистки Discord:
- 👤 **Личные сообщения (1-on-1 DMs)** — закрытие неактивных и старых личных диалогов.
- 💬 **Групповые чаты (Group DMs)** — выход из заброшенных бесед.
- 🛡️ **Серверы (Guilds)** — выход из ненужных сообществ (с защитой своих серверов).

---

## ⚡ Особенности

- **✨ Вход в 1 клик**: приложение умеет автоматически находить активные аккаунты Discord на вашем ПК (вам не нужно вручную копаться в консоли).
- **⏳ Умные фильтры**:
  - Быстрая кнопка «Выбрать старые (>30 дней без сообщений)».
  - Поиск по имени или `@username`.
  - Кнопки: «Выбрать все», «Снять выбор», «Инвертировать».
- **🛡️ Безопасность и Rate Limit**:
  - Настраиваемая пауза между запросами (по умолчанию 1.5 сек).
  - Автоматическая пауза при получении статуса 429 от Discord.
  - Защита от случайного удаления собственных серверов (где вы владелец).
  - Кнопка моментальной остановки процесса в любой момент.
- **🔒 Полная приватность**:
  - **Токен НЕ сохраняется на диск**. Он находится исключительно в оперативной памяти и стирается при закрытии окна.
  - Работает локально (`127.0.0.1`) без сторонних серверов.
  - **Zero dependencies**: не требует сторонних библиотек, работает на стандартном Python 3.

---

## 🚀 Быстрый запуск

### Windows
Дважды кликните по файлу **`run.bat`**.

### Терминал (Windows / macOS / Linux)
```bash
py main.py
# или
python3 main.py
```
После запуска браузер автоматически откроется по адресу `http://127.0.0.1:5055`.
